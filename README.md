# Void-Music-Player

A music player built with the Godot game engine. Scans for local music files and enables playback, playlist creation, queue control, and more.

Supports MP3, WAV, OGG Vorbis, and FLAC via [MiniAudio](https://github.com/mackron/miniaudio)

## Building

Building requires Godot 4.7.1-stable or later. After cloning the repo, run the [build script](build.sh), which will compile all dependencies and build the extensions for Godot. Exports can then be made via the editor.
